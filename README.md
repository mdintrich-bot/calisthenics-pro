# 🔥 CALISTHENICS PRO — Street Workout & Skills Tracker

Tableau de bord interactif de suivi d'entraînement en **Street Workout & Calisthénie**, conçu en une seule page (Single-File Web App).

## ✨ Fonctionnalités
- **Gestion de Routines** : Création de routines personnalisées avec sélection d'exercices par catégories (Pull, Push, Figures/Skills, Core & Jambes).
- **Suivi Objectif vs Réalisé** : Saisie des répétitions réussies série par série en fin de séance avec calcul du taux de complétion.
- **Auto Level-Up (Surcharge Progressive)** : Augmentation automatique de l'objectif (+1 rep ou +2.5 kg de lest) lorsque 100 % des séries sont validées.
- **Module Figures & Skills** : Suivi dédié aux figures (*Muscle-Up, Front Lever, Handstand, Planche, L-Sit...*) avec gestion des variantes (*Tuck, Adv. Tuck, Straddle, Full*).
- **Tests de Max (Hors Routine)** : Enregistrement des records sur 1 série, max lesté ou maintien isométrique maximal.
- **Graphiques & Records (Chart.js)** : Visualisation de la progression par exercice et tableau des records personnels (PR).
- **Chronomètre Double Mode** : Minuteur de repos (1m30 / 2m00) et chronomètre montant pour les maintiens statiques.
- **Sauvegarde Cloud & JSON** : Synchronisation automatique et export/import manuel en `.json`.

## 🚀 Technologies
- HTML5 / JavaScript ES6+
- Tailwind CSS (CDN)
- Chart.js
- Lucide Icons
- Firebase Firestore / LocalStorage Fallback
